# 🛡️ Security Policy

## Supported Versions

The following versions of this project are actively maintained with security patches and updates:

| Version | Status             |
| ------- | ------------------ |
| 5.1.x   | ✅ Actively Supported |
| 4.0.x   | ✅ Supported (Legacy) |
| 5.0.x   | ❌ Unsupported      |
| < 4.0   | ❌ Unsupported      |

Users are strongly encouraged to use the most current supported version to ensure access to the latest security improvements.

---

## Reporting a Vulnerability

If you believe you have identified a security vulnerability, we appreciate your responsible disclosure. Please follow the process below:

### 📫 How to Report

- Email: **osmanamel@outlook.com**
- Subject: `Security Disclosure – [Project Name]`
- Include:
  - A clear description of the issue
  - Steps to reproduce (proof-of-concept appreciated)
  - Affected versions or components
  - Any recommended remediation or workaround

**Note:** Do **not** disclose vulnerabilities publicly until they have been verified and patched.

---

### 🔄 Response Timeline

We are committed to timely and transparent communication. You can expect:

| Action                         | Estimated Timeframe      |
| ------------------------------|-------------------------- |
| Initial Acknowledgment         | Within 48 hours           |
| Triage & Validation            | 3–5 business days         |
| Remediation & Patch (if valid) | As soon as reasonably possible |
| Public Disclosure              | Coordinated with reporter |
